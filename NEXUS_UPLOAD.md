# Steering Speed Configurator

This mod allows you to dynamically adjust the turning and re-centering speed of the steering wheel for all vehicles in Cyberpunk 2077. Stop suffering from slow, unresponsive, or overly jerky steering — set the speed exactly how you like it!

## Features
- **Dynamic Configuration:** Adjust the turning and re-centering speed on the fly using Mod Settings. No game restart required!
- **Wide Range:** Choose from 0.5x (slower) to 1000x (insanely fast) multipliers.
- **Universal Compatibility:** Applies to all cars and bikes in the game automatically.
- **Lightweight:** Written purely in Redscript utilizing the power of TweakXL. No C++ DLLs, meaning it will survive most game updates without breaking.

## Installation
1. Install all the requirements listed above.
2. Download this mod and extract the `.zip` archive directly into your main Cyberpunk 2077 installation folder (the folder containing `bin`, `r6`, `archive`, etc.).
3. The file structure should look like this: `Cyberpunk 2077/r6/scripts/steering_speed/`.

## How to Use
1. Launch the game and go to the Main Menu or Pause Menu.
2. Click on **Mods** -> **Steering Speed**.
3. Adjust the "Steering turn speed" and "Steering re-center speed" sliders to your liking.
4. Jump into any vehicle and test it out! If you want to tweak it further, simply open the menu again and adjust the sliders. The changes apply immediately upon entering a vehicle.

## Uninstallation
Delete the following folder:
- `Cyberpunk 2077/r6/scripts/steering_speed/`

[size=6][b]Steering Speed Configurator[/b][/size]

This mod allows you to dynamically adjust the turning and re-centering speed of the steering wheel for all vehicles in Cyberpunk 2077. Stop suffering from slow, unresponsive, or overly jerky steering — set the speed exactly how you like it!

[size=5][b]Features[/b][/size]
[list]
[*] [b]Dynamic Configuration:[/b] Adjust the turning and re-centering speed on the fly using Mod Settings. No game restart required!
[*] [b]Wide Range:[/b] Choose from 0.5x (slower) to 1000x (insanely fast) multipliers.
[*] [b]Universal Compatibility:[/b] Applies to all cars and bikes in the game automatically.
[*] [b]Lightweight:[/b] Written purely in Redscript utilizing the power of TweakXL. No C++ DLLs, meaning it will survive most game updates without breaking.
[/list]

[size=5][b]Installation[/b][/size]
[list=1]
[*] Install all the requirements listed above.
[*] Download this mod and extract the .zip archive directly into your main Cyberpunk 2077 installation folder (the folder containing bin, r6, archive, etc.).
[*] The file structure should look like this: [b]Cyberpunk 2077/r6/scripts/steering_speed/[/b]
[/list]

[size=5][b]How to Use[/b][/size]
[list=1]
[*] Launch the game and go to the Main Menu or Pause Menu.
[*] Click on [b]Mods[/b] -> [b]Steering Speed[/b].
[*] Adjust the "Steering turn speed" and "Steering re-center speed" sliders to your liking.
[*] Jump into any vehicle and test it out! If you want to tweak it further, simply open the menu again and adjust the sliders. The changes apply immediately upon entering a vehicle.
[/list]

[size=5][b]Uninstallation[/b][/size]
Delete the following folder:
[b]Cyberpunk 2077/r6/scripts/steering_speed/[/b]
